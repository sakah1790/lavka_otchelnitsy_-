# Лавка отшельницы — One-Page Single Page Application (SPA)

Одностраничный сайт мастерской авторских кастомных изделий и украшений «Лавка отшельницы».
Все разделы (Главная, Каталог, Отзывы, За кулисами, Заказ, О лавке, FAQ) расположены на одной странице с плавной прокруткой и подсветкой активного пункта меню.
